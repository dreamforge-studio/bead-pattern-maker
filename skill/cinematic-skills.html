What job it does, what it saves

Intro page — the core method in one line: replace adjectives like 'cinematic' with camera instructions — position + move + start/end frames + speed. Stated honestly: this is a method-only set that we have not yet tested in production; until it is tested, it does not enter our production SOP and is not quoted to clients.

What's inside / the method

  • 22 camera moves with example prompts and a selection cheat sheet keyed by emotion and scene job
  • 9 look-alike move pairs disambiguated: pan vs truck, zoom vs dolly, and more
  • One main move per shot; at most two, joined by a trigger point
  • Six-layer shot spec: subject / shot size / angle / lens / move / rhythm and limits
  • Still-to-cinema trio: upscale depth plate → beat-grid sample → a living element inside the frame
  • Frame 0 is the cover: the opening frame must already be fully composed
