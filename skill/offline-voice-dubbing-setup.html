What job it does, what it saves

Cloud text-to-speech subscriptions charge you every month for a voice pipeline you could run on your own machine. The underlying tool is free and open source; what you pay for is our tested configuration and experience: the configuration route in working order, a one-pass setup checklist where every item has a verification action, and the license red lines that decide whether you may take paid client work at all — settled before the first invoice, not after.

What's inside / the method

  • Full configuration route: connection and contract discovery, generation, transcription, cloning and dubbing settings, and automation hooks (REST and MCP endpoints), in the order we run them
  • Local API documented (default http://localhost:3900); models work offline once installed
  • One-pass setup checklist — every item has a verification action
  • Version-update note sheet, so an upstream upgrade never silently breaks your setup
  • Red-line chapter: the Chinese-dubbing route, voice-cloning authorization rules, and the AGPL commercial-use red lines — the tool is AGPL-3.0 with separate Pro and Cloud tiers
  • The software itself is not included and is not redistributed: you get it from its official open-source repository, and the pack shows how to verify you have the right publisher before downloading
  • Honest caveat: cloud translation, model downloads and remote backends are optional external actions, so 'fully offline' is a claim to make only for the parts that actually are
