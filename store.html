Audio QC for AI Video — Skill Kit

Problem it solves

AI generators leave their own scratch voice under your dub. Lines come out twice, a line gets buried and never lands, or a sentence from an earlier take survives the edit. Your ears miss it on the tenth listen; a client or a platform reviewer won't. This kit is the machine gate that catches it before delivery.

What's inside

  • SKILL.md — the three checks (line integrity, leftover speech, loudness), how the transcript matching works, the workflow, the field record, and the known ASR pitfalls to check before condemning a cut
  • tools/audio_qc.py — the runnable checker: transcribes the finished file locally (faster-whisper), matches every script line (coverage ≥ 0.75), flags unmatched speech ≥ 8 characters, measures integrated loudness, exits 0 on PASS / 1 on FAIL so it can gate a pipeline
  • Report template — the line-table QC report format
  • START-HERE.md — install + first-run guide, about 10 minutes

Who it's for

AI video makers and freelancers delivering anything with dubbed or generated speech: series episodes, short dramas, talking-head cuts, client deliverables. Run it on the finished file — not the project timeline — whenever the script is locked and the mix is final.

What you get

One zip: SKILL.md, the checker script, the report template, install guide, license. On your machine you need ffmpeg and Python 3 with faster-whisper and numpy (optional opencc for Chinese normalization). No subscription. License: own productions and paid client work; no resale or redistribution.

How to use it

Install SKILL.md, save your locked script as one spoken line per line, then run python3 tools/audio_qc.py <finished-cut.mp4> <script-lines.txt> — read the PASS/FAIL report, fix, re-run. A cut ships only on a clean PASS. Field record: on a finished 60-second episode that had already passed a human listen, this gate found 6 lines heard twice — the generator's embedded voice had survived under the re-dub.
